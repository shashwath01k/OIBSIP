# OIBSIP – Oasis Infobyte Internship Projects

This repository contains the projects completed as part of the **Oasis Infobyte Internship (OIB-SIP May P1 2026)**.

## Tasks Completed

### Task 1 – Iris Flower Classification

Built a machine learning model to classify iris flowers into:

* Setosa
* Versicolor
* Virginica

using flower measurements.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
